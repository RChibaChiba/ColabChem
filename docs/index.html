ColabChem

Google Colab で開いて「すべて実行」を押し、構造ファイルを選ぶだけ。Meta の機械学習ポテンシャル UMA による構造最適化・スキャン・遷移状態探索と、DFT の一点計算・静電ポテンシャル・分子軌道（HOMO・LUMO）の表示ができます。

ColabUMA：UMA を使うノート

ColabUMA Opt

構造最適化。振動計算と、最適化した構造での DFT 一点計算もできます。

入力
xyz または gjf を1つ
主な出力
最適化構造、GaussView で開ける経路と振動、DFT のエネルギー
Colab で開く

ColabUMA Scan

結合長・角度・二面角の緩和スキャン。Gaussian の opt=modredundant の S 指定に相当します。

入力
xyz または gjf を1つ
主な出力
各点のエネルギー（CSV）と構造、スキャン前後の最適化構造
Colab で開く

ColabUMA TS

遷移状態探索。DMF で経路を求めて Sella で最適化し、虚振動・簡易 IRC・DFT 一点計算まで行います。

入力
原子の順番がそろった反応物と生成物、または TS の初期構造
主な出力
TS 構造、虚振動、反応経路、Gaussian 用 gjf、活性化エネルギー
Colab で開く

ColabUMA Workflow

最適化 → スキャン → 遷移状態 → DFT 一点計算を、1つのセッションで続けて実行します。インストールとモデル読み込みは1回で済みます。

入力
xyz または gjf を1つ
主な出力
全段階の結果をまとめた ZIP
Colab で開く

ColabDFT：UMA を使わないノート

トークン不要

ColabDFT SPE

入力した構造のまま、GPU4PySCF で DFT の一点計算だけを行います。

入力
xyz または gjf を1つ
主な出力
エネルギーを書き込んだ xyz、DFT のエネルギー（CSV）
Colab で開く
トークン不要

ColabDFT ESP

入力した構造のまま DFT の一点計算を行い、静電ポテンシャル（ESP）を等密度面に色付けして 3D 表示します。

入力
xyz または gjf を1つ。エディタで構造を描いても入力できます
主な出力
ESP の 3D 表示、ESP と電子密度の cube ファイル、面の上の最小・最大
Colab で開く
トークン不要

ColabDFT MO

入力した構造のまま DFT の一点計算を行い、HOMO・LUMO などの分子軌道を等値面で 3D 表示します。エネルギー準位図をクリックすると、ほかの軌道に切り替えられます。

入力
xyz または gjf を1つ。エディタで構造を描いても入力できます
主な出力
エネルギー準位図と軌道の 3D 表示、軌道の cube ファイル、軌道のエネルギーと HOMO-LUMO ギャップ
Colab で開く

どれを使うか

やりたいことノート
構造を最適化したいOpt
結合や二面角を動かしてエネルギー変化を見たいScan
反応物と生成物、または初期構造から TS を探したいTS
1つの入力構造から TS まで続けて計算したいWorkflow
手元の構造のエネルギーを DFT で計算したいColabDFT SPE
手元の構造の静電ポテンシャルを見たいColabDFT ESP
手元の構造の HOMO・LUMO を見たいColabDFT MO

使い方

  1. 上の「Colab で開く」からノートを開く
  2. ランタイム → ランタイムのタイプを変更 で T4 GPU を選ぶ
  3. 入力フォームに、出力名・電荷・スピン多重度などを入れる
  4. ランタイム → すべて実行 を押す
  5. ファイル選択ボタンが出たら構造ファイルを選ぶ。あとは放置できます
  6. 結果を確認し、ZIP をダウンロードする

ColabDFT ESP と MO では、フォームの入力を「描く」にすると、ファイルの代わりに構造エディタ（JSME）が出ます。描いて「この構造で計算」を押せば、水素を付けて 3D にしてから計算します。

初回のみ（ColabDFT 以外）： facebook/UMA でアクセスを申請して FAIR Chemistry License v1 に同意し、承認後に Read 権限のトークンを作ります。Colab の左サイドバーの🔑（シークレット）に名前 HF_TOKEN で登録し、ノートブックからのアクセスをオンにしてください。

注意事項

  • UMA は機械学習ポテンシャルであり、DFT の代わりにはなりません。最終的なエネルギー比較は DFT で確認してください。
  • 最適化は鞍点に収束することがあります。重要な構造は振動計算で確認してください。
  • TS ノートで見つかるのは UMA のポテンシャル面の TS です。最終的には DFT で TS 最適化と IRC を行ってください。
  • 扱える元素は、UMA を使うノートでは H〜Bi、ColabDFT では H〜Rn です。周期系には対応していません。
