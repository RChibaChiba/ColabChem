ColabChem

Open a notebook in Google Colab, choose "Run all" and pick a structure file. Geometry optimization, relaxed scans and transition state searches with Meta's machine learning potential UMA, plus DFT single points with views of the electrostatic potential and molecular orbitals (HOMO, LUMO).

ColabUMA: notebooks that use UMA

ColabUMA Opt

Geometry optimization, with a vibrational analysis and a DFT single point at the optimized structure.

Input
One xyz or gjf file
Main output
Optimized structure, path and vibrations that open in GaussView, DFT energy
Open in Colab

ColabUMA Scan

Relaxed scan of a bond length, angle or dihedral. Corresponds to the S entry of Gaussian's opt=modredundant.

Input
One xyz or gjf file
Main output
Energy at each point (CSV) and structures, optimized structures before and after the scan
Open in Colab

ColabUMA Conf

Conformer search. Optimizes structures collected by high-temperature MD, removes duplicates and reports the few lowest in energy. Works for a metal complex with a substrate.

Input
One xyz or gjf file (the complex with the substrate placed on it)
Main output
The lowest conformers (5 by default) with ΔE, DFT energies
Open in Colab

ColabUMA TS

Transition state search. DMF finds a path, Sella refines the TS, then the imaginary frequency, a simple IRC check and DFT single points.

Input
Reactant and product with the same atom order, or an initial TS guess
Main output
TS structure, imaginary frequency, reaction path, gjf for Gaussian, activation energies
Open in Colab

ColabUMA Workflow

Optimization → scan → transition state → DFT single point in one session, with a single install and model load.

Input
One xyz or gjf file
Main output
One ZIP with the results of every stage
Open in Colab

ColabDFT: notebooks without UMA

No token needed

ColabDFT SPE

DFT single point with GPU4PySCF on the input structure as it is.

Input
One xyz or gjf file
Main output
xyz with the energy written in, DFT energy (CSV)
Open in Colab
No token needed

ColabDFT ESP

DFT single point on the input structure, then the electrostatic potential (ESP) colored on an electron density isosurface in 3D.

Input
One xyz or gjf file, or a structure drawn in an editor
Main output
3D view of the ESP, ESP and density cube files, minimum and maximum on the surface
Open in Colab
No token needed

ColabDFT MO

DFT single point on the input structure, then molecular orbitals such as HOMO and LUMO as isosurfaces in 3D. Click the energy level diagram to switch to other orbitals.

Input
One xyz or gjf file, or a structure drawn in an editor
Main output
Energy level diagram and 3D view of the orbitals, orbital cube files, orbital energies and the HOMO-LUMO gap
Open in Colab

Which notebook to use

What you want to doNotebook
Optimize a structureOpt
Follow the energy while moving a bond or dihedralScan
Find a TS from a reactant and product, or from a guessTS
Go from one input structure all the way to a TSWorkflow
Get the DFT energy of your own structureColabDFT SPE
See the electrostatic potential of your own structureColabDFT ESP
See the HOMO and LUMO of your own structureColabDFT MO

How to use

  1. Open a notebook with "Open in Colab" above
  2. In Runtime → Change runtime type, choose T4 GPU
  3. Fill in the form: output name, charge, spin multiplicity and so on
  4. Choose Runtime → Run all
  5. When the file selection button appears, pick your structure file. You can leave it running after that
  6. Check the results and download the ZIP

In ColabDFT ESP and MO, setting input_mode in the form to draw shows a structure editor (JSME) instead of the file selection. Draw the molecule and press "Use this structure": hydrogens are added and a 3D structure is made before the calculation.

The forms, messages and logs in the notebooks are in English; error messages also show Japanese. The English README explains every form item.

First time only (all but ColabDFT): Request access at facebook/UMA and accept the FAIR Chemistry License v1. Once approved, create a token with Read access. In Colab's left sidebar, open 🔑 (Secrets), add it with the name HF_TOKEN, and turn on notebook access.

Notes

  • UMA is a machine learning potential, not a replacement for DFT. Check final energy comparisons with DFT.
  • An optimization can converge to a saddle point. Check important structures with a vibrational analysis.
  • The TS notebook finds a TS on the UMA potential energy surface. Finish with a TS optimization and IRC at the DFT level.
  • Supported elements are H–Bi in the UMA notebooks and H–Rn in ColabDFT. Periodic systems are not supported.
